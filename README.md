# Hawalek Super-App (منصة حواليك) 🚀

A multi-service super-app and commercial directory connecting business profiles, e-commerce stores, real estate, and travel booking.

## Technology
- Laravel 11
- React 19 and TypeScript
- Tailwind CSS
- MySQL
